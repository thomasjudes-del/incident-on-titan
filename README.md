# Incident on Titan — Weekly Incident Prototype

A mobile-first static prototype for **Incident on Titan (IOTI)**.

This version tests the current V0 game loop:

- one common weekly incident;
- one assigned role, shown without revealing Sybille AI's hidden priorities;
- five illustrated and causally linked human decision scenes;
- exactly three choices per scene;
- no consequence or calculation screen between choices;
- hidden Health, Energy and Science effects;
- deliberately paced terminal-style transmissions, skippable by tapping;
- a sixth and final command decision taken over by Sybille AI;
- a visible takeover effect using screen shake and a temporary colour shift;
- a deterministic nonlinear score labelled **Score attributed by Sybille AI**;
- English (US) and French interfaces using one shared game engine;
- one official attempt stored locally for the weekly mission;
- a PNG result card shared with the game link.

The current mission is **Incident 007 — The Black Window**, with the player acting as **Captain**.

This remains a static GitHub Pages prototype. The scoring logic is client-side for now and will move server-side only if the game loop is validated.
